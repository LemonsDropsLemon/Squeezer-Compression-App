# Squeezer-Compression-App
Well its a local desktop compression app :]

Download
https://github.com/LemonsDropsLemon/Squeezer-Compression-App/releases/tag/1.0.0v

Squeeze helps reduce file sizes directly on your computer without uploading your files anywhere

## Features
- Compress files locally on your device
- Support for files up to 10 GB each
- Adjustable compression quality
- CPU usage settings
- Live compression progress
- Download files individually or all at once
- Simple drag drop or open file interface

## Installation

1. Download the setup and run

## Privacy

All compression takes place locally on your device. Files are not uploaded to external servers.

## Requirements
- Windows, macOS or Linux.
**- Node.js and npm for development.**
- Sufficient RAM and storage **for larger files.** 10GB minimum
